# ドロワー表示中の右スワイプは何もしない（背後の右パネルを畳まない）

- Status: accepted
- Date: 2026-10-24
- Task: T308（ADR-20261023-1750 の優先順位に前段を追加。1750 の他の内容は変えない）

## Context

ADR-20261023-1750 は「右パネル表示中は、右スワイプでまず右パネルを畳む」と定めている。ただし、ドロワーが開いている
状態は考慮していなかった。このため、ドロワー上の左端から右スワイプすると、見えていない背後の右パネルが畳まれていた
（docs/spec.md Q2）。ユーザーはこれを「意図していない」と回答した（2026-10-24）。

## 選択肢

1. PHONE かつドロワーが開いているとき、右スワイプは何もしない。
2. ドロワーを閉じる（左スワイプと同じ扱いにする）。

## 決定

選択肢 1。

## 理由

- 方向の意味を保つため。右スワイプは「開く／戻る」で、閉じるのは左スワイプ。2 は同じ方向の操作に逆の意味を与えてしまう。
- 開いているものを右スワイプでさらに開く操作は存在しない。何もしないのが最小の変更になる。
